= RSR Outline
:toc:

`CoprocessorRuntime.jl` follows the Rhodium Standard Repository (RSR)
conventions of the hyperpolymath estate (badge in the root `README.adoc`). This
repository was minted from `rsr-template-repo`; it is *not* that template. It is
a Julia library, and the package itself is described in `README.adoc` and
`EXPLAINME.adoc`.

This file used to be a copy of the template's own overview ("the canonical
template for RSR projects", with its quick start, recipe list and file
checklist). That text described the template, not this package, and has been
removed. The RSR outline itself is maintained upstream, in
`docs/RSR_OUTLINE.adoc` of https://github.com/hyperpolymath/standards[hyperpolymath/standards].

== `.well-known` metadata

The RFC 8615 metadata files live in `www/.well-known/` in this repository:
`security.txt`, `ai.txt`, `humans.txt` and `aibdp.json`. A repository-root
`.well-known/` is the legacy location. This repository has none;
`scripts/migrate-wellknown-to-www.sh` moves one into `www/.well-known/` and
`scripts/sweep-wellknown.sh` drives that across repositories (`rsr-template-repo#53`).
`www/README.adoc` describes the `www/` bundle.
