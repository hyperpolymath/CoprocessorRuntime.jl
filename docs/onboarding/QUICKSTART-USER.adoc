= CoprocessorRuntime.jl — Quick Start for Users
:toc:

== What is CoprocessorRuntime.jl?

A host-side contract and evidence layer for coprocessor launches. It models
host and device roles, resource grades, transfer residues, launch receipts and
CNO/OND claims. It records launch semantics; it does not run accelerator
kernels.

It is a Julia library. There is no application to start and no service to run:
you load it with `using CoprocessorRuntime` and call it from your own code.

== What it is not

* It does not execute CUDA, ROCm, Metal or TPU kernels. That is `CUDA.jl`,
  `AMDGPU.jl`, `Metal.jl` or `KernelAbstractions.jl`.
* It does not select a backend. That is `AcceleratorGate.jl`.
* It does not heal a failing kernel. That is `HardwareResilience.jl`.
* It does not prove CNO/OND. That is `absolute-zero`. A claim here has status
  `:unproved` or `:model_checked`.
* It does not close K-CUT. That conjecture is open in `choreographic-types`.

== Prerequisites

* Julia 1.10 or later. Continuous integration runs 1.10 and the latest 1.x.
* No other packages. `Project.toml` lists no runtime dependencies.

== Install

The package is not in the Julia General registry and is not going to be
released there, so install it from its repository:

[source,julia]
----
using Pkg
Pkg.add(url="https://github.com/hyperpolymath/CoprocessorRuntime.jl")
----

This installs the `main` branch.

== First use

Save this as `first.jl` and run it with `julia --project=. first.jl` from the
environment you installed into:

[source,julia]
----
using CoprocessorRuntime

s = open_session(GPUKind())
plan = launch_plan(
    :matmul,
    [Endpoint(HostRole(), CPUKind()), Endpoint(DeviceRole(), GPUKind())],
    ResourceGrade(1 << 20, 10_000, 0.0),
    EchoResidue(collapsing_transfer(:f32_to_f16), "mantissa fibre"),
)

device_view = project(plan, DeviceRole())
println("kcut: ", device_view.kcut)

receipt = issue_receipt(s; warrant = WarrantOnly, claim = "planned")
println("host may claim: ", host_may_claim(receipt))

try
    universal_hub_allowed()
catch err
    println("refused: ", typeof(err))
end

close_session!(s)
println("session open: ", isopen(s))
----

Expected output:

[source]
----
kcut: open
host may claim: false
refused: HubCeilingRefusal
session open: false
----

What it shows:

* `project` gives one endpoint's view of the launch plan. The K-CUT field stays
  `:open`: the package does not claim to have closed it.
* A receipt issued with `WarrantOnly` is not factive, so the host may not claim
  the launch happened.
* `universal_hub_allowed()` always throws `HubCeilingRefusal`: one adapter
  cannot speak every vendor protocol.

== Optional: AcceleratorGate

If `AcceleratorGate.jl` is also loaded, the package extension
`AcceleratorGateExt` adds methods of `coprocessor_kind` that map an
AcceleratorGate backend to the `CoprocessorKind` a session is opened against.
It records which kind a backend is; it does not select a backend or check that
a device exists.
