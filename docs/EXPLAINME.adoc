This file explains what `CoprocessorRuntime.jl` records, which source file holds
what, and where its claims stop. The `README.adoc` is the short version.

== What it is

A host-side contract and evidence layer for coprocessor launches. It models
host and device roles, resource grades, transfer residues, launch receipts and
CNO/OND claims. It records launch semantics; it does not run accelerator
kernels, and it has no dependencies beyond Julia itself (`[deps]` in
`Project.toml` is empty).

It is a Julia library, not an application. It is installed by URL, not from the
General registry (see `QUICKSTART.adoc`).

== What it records

[cols="1,2,2",options="header"]
|===
| Question | Answer in this package | Source

| Which endpoint am I?
| `HostRole` / `DeviceRole`, projected out of a `LaunchPlan`
| `src/Kinds.jl`, `src/Choreography.jl`

| What is the worst-case cost?
| `ResourceGrade`: bytes, nanoseconds, joules; `tropical_seq` adds, `tropical_alt` takes the maximum
| `src/Grades.jl`

| What was lost in the transfer?
| `EchoResidue` on a `TransferMap` that is, or is not, injective and reversible
| `src/EchoLoss.jl`

| What may the host claim afterwards?
| `LaunchReceipt` with a standpoint, a `WarrantKind` and a `sound` flag
| `src/Receipts.jl`

| Did a reset do nothing, and did a channel reveal nothing?
| `CNOClaim` and `ONDClaim`, whose `status` is `:unproved` or `:model_checked`
| `src/Nullity.jl`

| Can one adapter speak every vendor protocol?
| No: `universal_hub_allowed()` throws `HubCeilingRefusal`
| `src/Choreography.jl`
|===

== Where each piece lives

`src/CoprocessorRuntime.jl` declares the module, the export list and the
`include` order. The seven files it includes:

| `Grades.jl`
| `ResourceGrade` (rejects negative fields), `tropical_seq`, `tropical_alt`, `dominates`

| `EchoLoss.jl`
| `TransferMap`, `EchoResidue`, `injective_transfer`, `collapsing_transfer`

| `Sessions.jl`
| `Session{K}`, `open_session`, `close_session!`, `isopen`

| `Receipts.jl`
| `WarrantKind` (`Knowledge`, `Belief`, `WarrantOnly`, `Unsound`), `LaunchReceipt`, `issue_receipt`, `host_may_claim`

| `Nullity.jl`
| `CNOClaim`, `ONDClaim`, `InverseMeta`, `inversion_of`, `irreversible`, `reset_session!`, `observe_null`

| `Endpoint`, `LaunchPlan`, `launch_plan`, `project`, `projected_grade`, `HubCeilingRefusal`, `universal_hub_allowed`

== Reading the claims honestly

These rules are in the code, and they are the point of the package:

* *A session is a handle.* `open_session` allocates nothing on a device and
  does not prove a device exists (`src/Sessions.jl`).
* *Receipts default to unsound.* `issue_receipt` sets `sound = false` unless
  told otherwise. `host_may_claim` is true only for a `:host` standpoint with
  `Knowledge` warrant and `sound == true`. A `:device` standpoint with
  `Knowledge` and no soundness check is refused with an `ArgumentError`
  ("smuggling") (`src/Receipts.jl`).
* *CNO and OND are claims, not proofs.* `reset_session!` reports
  `:model_checked` when the handle came back with the same id and open; that is
  a host-side handle check, not a device reset. `observe_null` defaults to
  `:unproved` and accepts only `:unproved` or `:model_checked`
  (`src/Nullity.jl`).
* *Unstated energy is not free.* `joules == 0.0` means unstated, and unstated
  energy does not dominate a stated energy (`src/Grades.jl`).
* *K-CUT stays open.* `project` always returns `kcut = :open`. It returns
  `grade_eq = true` only when the plan's transfer map is injective, and
  otherwise `warrant_bound = :open` (`src/Choreography.jl`).

== The AcceleratorGate extension

`AcceleratorGateExt` is loaded by Julia only when `AcceleratorGate.jl` is also
loaded (`[weakdeps]` and `[extensions]` in `Project.toml`). It adds methods of
`coprocessor_kind` that map an AcceleratorGate backend type to a
`CoprocessorKind`, so a session can be opened with
`open_session(coprocessor_kind(backend))`. It selects nothing and runs nothing.
Four backends (`PPUBackend`, `MathBackend`, `VPUBackend`, `CryptoBackend`) map
to `UnknownKind`, because this package has no kind for them. Without
AcceleratorGate loaded, `coprocessor_kind` has no methods and a call is a
`MethodError`, on purpose.

== What it is not

* Not an executor of CUDA, ROCm, Metal or TPU kernels: that is `CUDA.jl`,
  `AMDGPU.jl`, `Metal.jl` and `KernelAbstractions.jl`.
* Not a backend selector: that is `AcceleratorGate.jl`.
* Not a healer of failing kernels: that is `HardwareResilience.jl`.
* Not a proof of CNO or OND: that is `absolute-zero`. Status here is
  `:unproved` or `:model_checked`.
* Not a closure of K-CUT: that conjecture is open in `choreographic-types`.

== Around the package

The repository also carries estate scaffolding that is not part of the Julia
API: the local session bindings in `session/` (see `session/README.adoc`), the
`Justfile`, CI under `.github/workflows/`, and the machine-readable state under
`.machine_readable/`. `architecture/REPOSITORY-MAP.adoc` is the generated map
of the tree.
