= Template identity removed from the A2ML files, 2026-11-17

This repository was minted from `rsr-template-repo` but kept the template's own
identity. The deed header and `CLAUDE.md` now state this repository's own
identity (`CoprocessorRuntime.jl_chora.deed`; the arrival pack is generated
from it). This record covers the `.a2ml` files that still declared the
template. It follows the shape of boj-server's `docs/history/A2ML-REMOVED.adoc`.

A2ML is retired. The only edit made to any `.a2ml` file was deleting lines: no
line was added or changed, no file was created or restored, and nothing was
converted. Git history keeps the old content; read a file with
`git show 6ccf6c9:<path>`. Size and sha256 prefix are of the file as it stood
at 6ccf6c9; the blob id is its git blob.

== No `.a2ml` file was removed

Removing `CLADE.a2ml` and `ECOSYSTEM.a2ml` was tried first and rejected. With
the files removed, `just validate-rsr`, `scripts/validate-template.sh`, the Must
clause `six-directory-present` and the coaptation tooling all fail. With
deletion-only stubs they all pass, except that the coaptation still fails as it
already did on main (see below). The two files are therefore kept as stubs.

== Readers, and what they see now

* `build/just/validate.just` (`validate-rsr`), `assess.just`, `groove.just` and `scripts/validate-template.sh` test that `ECOSYSTEM.a2ml` exists. It does, so they pass.
* The Must clause `six-directory-present` tests that `ECOSYSTEM.a2ml` exists. It does, so it passes.
* `.github/hooks/validate-deed.sh` and the upstream `deed-ecosystem` validator accept all the edited files.
* `.machine_readable/coaptation/` reads `CLADE.a2ml`, `ECOSYSTEM.a2ml` and `STATE.a2ml`. Its committed receipt was already stale on main and still is. The stubs lose the facts `clade.*` and `ecosystem.type`, so a fresh run now reports the witness `must.six-directory-present` as refuted and the band as red (it was green fresh on main). This is not run in CI. Moving the coaptation to the deed needs the contractile K9 files moved off the missing `../k9/template-hunt.k9.ncl` first, which is a separate change; once done, the stubs can be deleted.

== Where the identity went

* `CoprocessorRuntime.jl_chora.deed`: header ids; `(identity)`, `(forges)`, `(lineage)`, `(status)`, `(maturity)`, `(ecosystem)` with its `(related …)` entries; a minimal `(anchor)`; `(ply)` at the template's text. The clade is left unassigned, since chora-registry is authoritative for it.
* `CLAUDE.md` "This repo" block: generated by `just claude-md` from the deed.
* Non-A2ML files that named the template as this repo (`CONTRIBUTING.adoc`, `.github/{CONTRIBUTING,SECURITY,CODE_OF_CONDUCT}.md`, `build/guix.scm`, `.machine_readable/contractiles/Justfile`, `docs/onboarding/*`, the Justfile echoes and the SonarCloud comment): rewritten by the template's own self-name rule from `build/just/repo-init.just`, with every hunk read.
